API Keys
Create an API key
POST/v1/keys
Creates a new API key scoped to a single environment. Keys are shown in full exactly once — store the returned secret immediately.
Authentication
All requests to the Relay API must include a workspace-level access token in the Authorization header. This endpoint cannot be called with a scoped API key — only a workspace owner or admin token.
Note — the response's secret field is only ever returned on creation. Relay does not store or display full key values afterward.
Parameters
namerequired
string
A human-readable label for this key, e.g. "CI pipeline".
environmentrequired
string
One of production, staging, development.
scopes
array
Permission scopes, e.g. ["read:requests","write:endpoints"]. Defaults to full access if omitted.
expires_at
string · ISO 8601
Optional expiration timestamp. Keys never expire by default.
Response
Returns the created key object, including the plaintext secret (shown once).
cURL
JavaScript
Python
Copy# create a production key curl -X POST https://api.relay.dev/v1/keys \ -H "Authorization: Bearer $RELAY_TOKEN" \ -H "Content-Type: application/json" \ -d '{ "name": "CI pipeline", "environment": "production" }'
